# Donanim sinyali -> firmware fonksiyonu haritasi (YA4000D)

Sinyal isimleri: 4021/4025 Depo Bakim Onarim kilavuzu, bolum 3.6.2.3 (K3 Kontrol ve SF karti, TD1 M37732S4LGP).
Fonksiyon adlari YA4000D.asm etiketleridir. "yon" = data direction register erisimi.

## Kesme vektorleri

| Vektor | Handler | Donanim baglantisi (kilavuz/sema) |
|---|---|---|
| UART0_RX | L_019469 | RS232 (P82 RxD0) |
| UART0_TX | L_0195B2 | RS232 (P83 TxD0) |
| ZERODIV | L_01B9A0 | sifira bolme |
| BRK | L_01B9AB | BRK |
| DBC | L_01B9B6 | debug |
| WDT | L_01B9C1 | watchdog |

| TA3 | L_01BB88 | zaman asimi / sentezor kilit bekleme |
| TB1 | L_01C627 | P66 SC_COZME (secmeli cagri sifir-gecis girisi) |
| TA1 | L_01C6C0 | P52 SC_TON uretimi (TA1OUT) olasi |

## Port yon ayarlari (main, 0x01A6D5) - semayla tutarlilik kontrolu

| Register | Deger | Cikis pinleri | Yorum |
|---|---|---|---|
| P4D | 0x4C | P42?, P43, P46 | P43 KRISTAL_KAYDIRMA cikis (sema DTR1 surer). P46 bu firmware'de cikis |
| P5D | 0x7F | P50-P56 | P57 SUSTURMA giris (squelch algilama) - kilavuzla uyumlu |
| P6D | 0x02 | P61 | P61 SCL cikis; P62 SDA open-drain (yon register'i ile suruluyor = bit-bang I2C) |
| P7D | 0x07 | P70, P71, P72 | P70 SENT_YUKLE, P71 GUC_ACMA (TR101 tutma), P72 cikis; P73-P77 analog giris |
| P8D | 0xAA | P81, P83, P85, P87 | SENT_SEC, TxD0 (RS232), CLK1, TxD1 (C-BUS/sentezor) - sema ile birebir |

Not: Kilavuz 4021/4025 arac / 4031/4035 sabit telsizleri icindir; firmware "4000/4100 serisi" diyor.
P46 ve P72 kilavuzda islev adiyla geciyor, yon belirtilmiyor; firmware ikisini de cikis yapiyor.
